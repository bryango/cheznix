# stubs

- These are stub options to make NixOS modules work.
- Most options are directly copied from NixOS with a no-op config.
- Forked options / config with concrete implementations should NOT be placed here.
- They can be safely removed if a concrete implementation emerges in e.g. upstream system-manager.

See: https://github.com/numtide/system-manager/blob/aefb4f3df0f6f1d50a885bd5beb004e9bfef0274/docs/site/how-to/import-nixos-module.md
